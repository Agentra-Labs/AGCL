**What it does:** Stores trained topic checkpoints (`links.pt`,
`centroid.pt`, `meta.json`) in object storage. Enables multi-node AGCL
workers to share the same model artifacts, and backs up agent state
durably.

> Part of the **[Cloud / infra integrations](../cloud.md)**.

---

## Supported backends (all use the same AWS S3 SDK)

| Provider | Endpoint | Notes |
|---|---|---|
| **AWS S3** | `https://s3.amazonaws.com` | Standard; free tier 5 GB |
| **Cloudflare R2** | `https://<account>.r2.cloudflarestorage.com` | Zero egress fees |
| **MinIO (self-hosted)** | `http://minio:9000` | Run on any server |
| **Backblaze B2** | `https://s3.us-west-004.backblazeb2.com` | $0.006 / GB / month |

## Install

```bash
pip install boto3 aioboto3
```

MinIO (self-hosted, Docker):

```bash
docker run -d -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=agcl \
  -e MINIO_ROOT_PASSWORD=agclsecret \
  -v minio-data:/data \
  minio/minio server /data --console-address ":9001"
```

## AGCL S3 storage client

```python
import io, os
import aioboto3
import torch

class S3CheckpointStore:
    def __init__(self):
        self.session = aioboto3.Session()
        self.bucket = os.getenv("AGCL_S3_BUCKET", "agcl-checkpoints")
        self.kwargs = dict(
            endpoint_url=os.getenv("AGCL_S3_ENDPOINT"),       # None = AWS, set for R2/MinIO
            aws_access_key_id=os.getenv("AGCL_S3_KEY_ID"),
            aws_secret_access_key=os.getenv("AGCL_S3_SECRET"),
        )

    async def save_checkpoint(self, topic_id: str, tensor: torch.Tensor, filename: str):
        buf = io.BytesIO()
        torch.save(tensor, buf)
        buf.seek(0)
        key = f"topics/{topic_id}/{filename}"
        async with self.session.client("s3", **self.kwargs) as s3:
            await s3.put_object(Bucket=self.bucket, Key=key, Body=buf)

    async def load_checkpoint(self, topic_id: str, filename: str) -> torch.Tensor:
        key = f"topics/{topic_id}/{filename}"
        async with self.session.client("s3", **self.kwargs) as s3:
            obj = await s3.get_object(Bucket=self.bucket, Key=key)
            buf = io.BytesIO(await obj["Body"].read())
            return torch.load(buf)
```

## Env vars

```env
AGCL_S3_BUCKET=agcl-checkpoints
AGCL_S3_KEY_ID=your-access-key
AGCL_S3_SECRET=your-secret-key

# For non-AWS (R2, MinIO, B2):
AGCL_S3_ENDPOINT=https://<account_id>.r2.cloudflarestorage.com

# Leave AGCL_S3_ENDPOINT unset for AWS S3
```

Many no-code / low-code platforms accept a static OpenAPI document in
place of a custom adapter. AGCL's node server already produces one.

> Part of the **[Agent-platform integrations](../integrations.md)**.

---

## Live spec

The node server exposes a complete OpenAPI document at
`/openapi.json` whenever it's running.

## Static dump

For platforms that want a static spec (Zapier Developer Platform,
Copilot Studio's "Add a plugin", Vertex AI Extensions), dump it once:

```bash
python main.py openapi --out agcl.openapi.json
```

Upload `agcl.openapi.json` to whichever portal asks for one. The
document is a strict subset of OpenAPI 3.0 generated by FastAPI so it
imports cleanly into all four target platforms.

---

## Where it works

| Platform | How |
|---|---|
| **Zapier** | Developer Platform → "Import OpenAPI Spec" |
| **n8n** | Webhook node + "OpenAPI" credential helper |
| **Copilot Studio** | "Add a plugin" → upload spec |
| **Vertex AI Extensions** | Console → "Create extension" → upload spec |

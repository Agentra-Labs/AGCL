# Collaboration & Progress Tracker

This folder tracks implementation progress and provides a shared space for AI agents and humans to review changes to the repo.

Conventions:
- Add progress notes as Markdown files named `short-description-DD-MM-YYYY.md` (uppercase placeholders, hyphen-separated).
- Inside each entry, write the date field as `YYYY-MM-DD` (ISO) and the time field in the **user's detected local timezone** (e.g. `21:18 PDT`).
- Keep entries concise: summary, files changed, rationale, verification status, and next steps.
- Prefer deltas over restating prior context.
- Maintain `CHANGELOG.md` as the top-level, chronological index: after every task, append a new entry at the top with date, time in the **user's detected local timezone**, and links to the detailed note(s). See `PROTOCOL.md` and the template in `CHANGELOG.md`.

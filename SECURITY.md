# Security Policy

## Supported Versions

Security updates are currently provided only for the latest stable release.

| Version | Supported |
| ------- | ---------- |
| 0.1.x   | ✅ |
| < 0.1   | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- Open a private security advisory on GitHub if available
- Or contact the maintainers directly

Please include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested fixes (if any)

You can expect:
- Initial acknowledgement within 72 hours
- Status updates during investigation
- Credit in release notes if desired

Please do not publicly disclose vulnerabilities until a fix has been released.
